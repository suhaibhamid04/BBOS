# Booking Bridge OS - Project Handoff Context

## Project Goal
**Booking Bridge OS** is a modular, AI-Powered Travel Business Operating System tailored for travel agencies operating in Kashmir, Jammu, Ladakh, and domestic India destinations. The core objective is to centralize and automate CRM, Sales Pipelines, Quotations, and Marketing campaigns using integrated AI Agents (Gemini) acting as copilots to human operators. 

The application must serve as a "Command Center" where multiple roles (Founder, Sales, Marketing) collaborate safely with Role-Based Access Control (RBAC) and human-in-the-loop AI approvals.

## What Has Been Completed (Current State)

### 1. Architecture & Infrastructure
- **Full-Stack Setup**: React 18 frontend built with Vite, served by an Express backend (`server.ts`). 
- **Production Ready**: Fully configured build pipeline combining Vite (frontend) and ESBuild (backend) into a standalone `dist/server.cjs` compatible with Cloud Run.
- **Fixed Runtime Bugs**: Addressed ESM/CJS compatibility issues (`import.meta.url`) to ensure stable production deployments.

### 2. Design System & UI/UX
- **Geometric Balance Theme**: Clean, structural UI built with Tailwind CSS. Utilizes an off-white canvas (`#F9FAFB`), slate borders, and primary brand accents (`#7056EE` Purple and `#F0A608` Amber).
- **Global Layout**: Persistent navigation sidebar with contextual metric badges, a global top header (Search, Demo toggle, Role Switcher), and a floating "Ask AI Bridge" action button.
- **Role Switcher**: Mock authentication context (`AuthContext.tsx`) allowing users to seamlessly switch between roles (Founder, Sales Agent, Marketing, etc.) to view different data slices.

### 3. Core Modules Built
- **Command Center Dashboard**: Features geometric KPI cards (Total Revenue, New Leads, Conv. Rate, Active Quotes), an active sales pipeline snapshot, priority operational tasks, and a dedicated AI Recommendations panel.
- **Sales & Pipeline**: Modular views for handling leads (New, Negotiation, Booked) and generating custom quotations for Himalayan packages.
- **Marketing & Content Hub**: Destination strategy matrices, Meta Ads campaign tracking, and AI-assisted content brief generation.
- **Demo Data Engine**: Robust mock data service (`demoData.ts` & `DataContext.tsx`) persisting to `localStorage` for immediate visual feedback and testing without a live database.

### 4. AI & Agent Integrations (Server-Side)
- **Gemini Foundation Models**: Secure, server-side implementation of the `@google/genai` SDK (`server/ai/aiClient.ts`). Features graceful fallbacks if API keys are absent.
- **Agent Roles**:
  - `salesAgent.ts`: Analyzes lead intent, generates WhatsApp drafts, and flags high-priority deals.
  - `marketingAgent.ts`: Generates ad copies, Instagram captions, and destination strategy insights.
  - `commandCenterAgent.ts`: Global orchestrator capable of querying the overall business state and suggesting executive actions.

## Next Steps / Directives for the Next Agent

If you are picking up this project from here, your immediate priorities should be:

1. **Database & Persistence Integration**:
   - The app currently runs on `localStorage` demo data. Transition the application to a real backend database (e.g., Firebase Firestore or Cloud SQL via Drizzle ORM). Use the structure in `types/index.ts` as the schema foundation.
2. **Authentication**:

4. **Expand AI Capabilities**:
